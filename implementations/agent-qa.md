# agent-qa

[agent-qa](https://vostride.com) runs plain-English tests for web, Android and iOS applications. Its memidex memory engine preserves verified application knowledge so later runs can reuse what earlier runs learned.

Completed runs produce candidate facts, cautions and procedures. A curator and evidence checks govern admission; accepted records inform later run briefs. Local runs can promote records backed by confirmed evidence, while CI runs only propose candidates. Records remain inspectable and reversible. Self-improvement operates through this reusable application knowledge.

This is an application of persistent agent memory to repeatable QA workflows. The project provides a CLI, local dashboard and local QA MCP server. Its license is FSL-1.1-ALv2; model/API and environment costs are separate.
